## Instructions

1.  Compile a list of high-level functional requirements for your class project
2.  Compile a list of high-level non-functional requirements for your class project.
    -   For each non-functional requirement, define a criteria to verify/validate the requirement.
    -   Verifiable non-functional requirement needs to have a measure that can be objectively tested 
3.  Compile a list of high-level domain-specific requirements for your class project

You can use ChatGPT, Google Gemini, Claude or another LLM to assist you in generating following set to requirements for your class project. Use the Business Plan, Use Cases and Story Boards as source documents.
