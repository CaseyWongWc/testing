## System Boundary

**System:** "A Forgotten Place" -- Zero-player survival horror simulation

The system is a real-time simulation where AI-controlled survivor agents navigate a grid-based map, fight zombie enemies, complete objectives, and attempt to evacuate through a portal. A human observer configures and watches the simulation unfold.

---

## Primary Actors

Primary actors initiate interactions with the system.

### 1. Observer (Human Player)

The human user who sets up, launches, and watches the zero-player simulation. They do not control survivors directly -- they configure parameters and observe AI behavior.

**Use Cases:**
- **Configure Simulation** -- Set map size (30x30, 40x40, 60x60), survivor count (1-5), difficulty, biome type, and objective count before a run starts.
- **Start Simulation** -- Launch the simulation run and begin the real-time tick loop.
- **Watch Simulation** -- Observe the simulation as it plays out in real time (the core zero-player experience).
- **Pause/Resume Simulation** -- Temporarily halt or continue the simulation.
- **Adjust Playback Speed** -- Change the tick rate / visual speed of the simulation.
- **View Performance Metrics** -- Review stats during or after the run (kills, score, rounds survived, exploration coverage).
- **View Game Results** -- See the win/lose outcome screen with final stats and score breakdown.

### 2. Survivor AI Agent

Autonomous AI-controlled characters that make decisions each tick based on their brain type (balanced, aggressive, defensive, cautious) and local information.

**Use Cases:**
- **Navigate Terrain** -- Move across the grid, accounting for terrain costs and obstacles using pathfinding (A*).
- **Explore Map** -- Reveal fog of war by moving into unexplored areas. Contributes to shared team fog.
- **Fight Enemies** -- Engage zombies in real-time combat using equipped weapons (melee or ranged).
- **Flee from Threats** -- Retreat from enemies when health is low or odds are unfavorable (brain-dependent).
- **Scavenge Resources** -- Pick up health packs, ammo, and items found on the map.
- **Activate Objective** -- Stand on an objective tile and hold to activate (hold-to-activate, N ticks, soft-locked in place).
- **Follow Compass** -- Use the compass indicator to navigate toward the current active objective.
- **Evacuate Through Portal** -- Enter the active (unlocked) portal to begin evacuation. Transitions to EVACUATING state.
- **Request Help** -- Call out for backup from nearby teammates (future: Phase 6).
- **Trade Items** -- Exchange resources with other survivors based on AI trade evaluation (future: Phase 3).

## Secondary Actors

Secondary actors respond to or support interactions initiated by primary actors or the system.

### 3. Zombie AI Enemy

AI-controlled hostile entities that pursue and attack survivors. Spawned by rift portals (spawners).

**Use Cases:**
- **Pursue Survivor** -- Move toward the nearest visible survivor using pathfinding.
- **Attack Survivor** -- Deal damage to a survivor within attack range.
- **Spawn from Rift** -- Be generated by a Spawner entity when cooldown expires and cap allows.

### 4. Spawner (Rift Portal)

Static entities on the map that generate zombie enemies at intervals.

**Use Cases:**
- **Generate Enemies** -- Produce new zombie entities based on spawn cooldown, max alive cap, and resource pool.
- **Scale Difficulty** -- Increase spawn rate or spawn stronger enemy types as rounds progress.

### 5. Game Clock / Tick Engine

The real-time loop (60 ticks/sec) that drives all simulation updates.

**Use Cases:**
- **Drive Simulation Loop** -- Execute the Sense/Decide/Act/Spawn/Cleanup cycle each tick.
- **Manage Day/Night Cycle** -- Transition between day and night phases, affecting vision range and enemy behavior (future: Phase 3).
- **Track Objectives** -- Update objective progress and trigger portal unlock when all objectives are complete.

### 6. Objective System

Manages the sequential chain of location-based objectives that must be completed to unlock the portal.

**Use Cases:**
- **Present Objective** -- Provide the current objective location and type to survivors (via compass).
- **Track Completion** -- Monitor objective progress and advance to the next objective when complete.
- **Unlock Portal** -- Set portal state to ACTIVE when all objectives in the chain are completed.

## Use Case Relationships

### Includes (shared behavior)

- "Activate Objective" **includes** "Follow Compass" (survivors use the compass to find objective locations)
- "Fight Enemies" **includes** "Navigate Terrain" (combat positioning requires movement)
- "Evacuate Through Portal" **includes** "Navigate Terrain" (must physically reach the portal tile)

### Extends (optional behavior)

- "Request Help" **extends** "Fight Enemies" (only triggered under specific conditions: low health, surrounded)
- "Flee from Threats" **extends** "Fight Enemies" (brain evaluates whether to fight or flee)
- "Trade Items" **extends** "Scavenge Resources" (trading is an alternative way to acquire needed items)
- "Adjust Playback Speed" **extends** "Watch Simulation" (optional observer action during viewing)
