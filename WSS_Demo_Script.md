# Wilderness Survival System - Demo Script

## Introduction (10-15 seconds)
"This is a demonstration of my Wilderness Survival System implementation. The system simulates an agent navigating through different terrains while managing resources and interacting with traders."

## Configuration Screen (20-30 seconds)
1. Show the configuration screen
2. Explain: "The system allows configuring the map size, difficulty level, vision type, and brain type before starting."
3. Select different options:
   - Map size: 15x15
   - Difficulty: Medium
   - Vision: Eagle
   - Brain: Strategic

## Gameplay Demonstration (60-90 seconds)
1. Start the game
2. Explain: "Here we can see the generated map with different terrain types represented by different colors."
3. Point out the different terrain types: "We have plains (green), forests (dark green), mountains (purple), deserts (yellow), and swamps (blue)."
4. Show resource management: "The player needs to manage strength, water, and food resources while navigating through the map."
5. Demonstrate movement: "I can move in 8 directions or stay in place. Each terrain type has different movement and resource costs."
6. Show brain reasoning: "The AI brain suggests moves based on its decision-making algorithm. We can see its reasoning here."
7. Enable auto-play: "I can enable auto-play to let the AI navigate autonomously."

## Trading Demonstration (30-45 seconds)
1. Find a trader on the map
2. Interact with the trader: "When encountering a trader, we can exchange resources."
3. Show the trading interface: "Here I can offer certain resources and request others."
4. Demonstrate trader behavior: "Depending on the trader type, they will respond differently to offers."
5. Complete a trade

## Vision Types (20-30 seconds)
1. Explain vision range: "Different vision types affect how much of the map is visible to the player."
2. Show how the visibility changes with movement

## Game Completion (15-20 seconds)
1. Show how to reach the eastern edge
2. Demonstrate game victory condition

## Conclusion (10-15 seconds)
"This demonstrates the key features of my Wilderness Survival System implementation, including terrain types, trader interactions, vision types, and brain algorithms."
